# Prepare documents with PaperLink

## Try an example first

Choose **Try an example** on the starting screen. It contains fictional employees and a salary letter.

1. Double-click **D2** in the spreadsheet and type **650**.
2. The increment and final salary in the letter update.
3. Use the arrows beside **One per row** to see the next employee.
4. Choose **Check pages**, then **Save file / Print** when you want a finished file.

Use your own spreadsheet and document for real work.

## 1. Open your files

Choose **Open file** above the spreadsheet on the left. Choose your Excel or other spreadsheet file.

Choose **Open file** above the document on the right. Choose your Word document, or click the blank page to start writing. You can also open **Templates** to reuse a document you prepared earlier.

## 2. Add information to the document

1. Click a spreadsheet cell containing the name or number you want.
2. Click where it belongs in the document. You can highlight existing text to replace it.
3. Choose **Add A2 to document**, or the button showing the cell you selected.

Green items stay connected. Change a green value in the document or its spreadsheet cell and both update. Blue items are calculated in the spreadsheet; change the numbers used in their formula.

For several cells, hold **Shift** and click another cell, then choose **Add selected cells as a table**.

You can also drag a spreadsheet cell into the document. Move the pointer to the exact place you want, then release at the **green insertion line**. The dragged label stays beside the pointer so it does not cover the text. A connected value already in the document can be dragged to another position the same way. Press **Escape** to cancel a drag.

Choose **More tools** for tables, headings, page breaks, images, and headers/footers. Use **Connected information** if you need to change where a value comes from.

## One document or one per row?

- **One document** prepares one document using the cells you choose.
- **One per row** prepares a document for each filled row, such as each employee.

For One per row, use the arrows to check each document. **Choose rows** lets you choose the sheet and the row containing the headings. Usually the headings are on row 1, with the people or items below it.

Connected items on that sheet can change with each row. Whole tables with several rows stay the same in each document.

## 3. Check and save

Choose **Check pages** to see how the document is laid out. Check the names and numbers, then choose **Save file / Print**.

Headers and footers fit automatically, including with narrow margins. When they need more room, the document text moves onto another page. You do not need to keep increasing the bottom margin. Page numbers stay below the footer. If a header or footer fills almost the entire page, shorten it under **More tools → Header / footer**, or choose a taller page under **Page setup**.

- Choose **Word document** for a file you can edit in Word.
- Choose **PDF document** for a finished file to share or print.
- For One per row, choose one file containing all documents or separate files in a ZIP folder.
- Choose all pages, the selected preview page, or your own page numbers.

### Name each file in a ZIP

1. With **One per row**, choose **Separate files in a ZIP folder**.
2. Enter a **ZIP file name** for the folder containing the documents.
3. Under **Name the files inside the ZIP**, choose a column such as **Employee name**. You can add text before each name, such as **Salary notice**.
4. Check the names below. You can type a different name for any row. For example, a PDF might be **Salary notice - Iris.pdf**.
5. Choose **Save file**. File endings are added for you. Matching names get numbered so no document is lost, and empty cells use their row number.

**Reset individual names** returns to the suggested names. Individual edits stay while this window is open. If a document has several pages and you save as pictures, its named file is a ZIP containing those pages.

## Send document emails or save drafts

Choose **Email documents**, enter your sender address, and write the subject and message. Enter **To** and optional **CC** directly in **3. Review each email**. Each person keeps their own addresses. Optional **Fill addresses from spreadsheet columns** fills addresses automatically. Choose PDF or Word attachments. In **One per row**, each email gets its own row's document.

For bulk sending, choose **How many emails? → One email per spreadsheet row** inside the email window, then choose the sheet and headings row. Check **Recipients and their attachments**, choose **Review** to edit a person's To and CC, and use **Preview this person's document** to inspect the content. Correcting addresses reuses prepared documents; **Reset addresses** restores that email's source values.

To require a password when opening PDF or Word attachments, choose **Password protection** under **2. Attach the document**. Enter and confirm a shared password, or choose a spreadsheet column containing a password for every included person. Share passwords separately. Typed passwords are cleared when this window closes; password cells remain in your workbook. Choose **Prepare emails** again after changing protection settings.

For direct sending, expand **Email server settings** and enter your company's SMTP server, port, security, username, and password. Use **Test connection**, then **Send test email** to your own address first. This sends a plain test message without payroll attachments or CC.

Review the document emails with the arrows, then choose **Prepare emails** and **Send this email** or **Send all emails**. Review the final confirmation before sending. Check the results shown for each email. **Stop remaining** stops after the current email finishes. A server acceptance is not an inbox-delivery receipt.

To work in another email app, use **Open this draft**, **Save drafts (.zip)**, or the copy buttons and **Save attachment**. See [the email guide](EMAIL-DRAFTS.md).

## Keep your progress or reuse a layout

**Save work** keeps the spreadsheet, document, and connections in this app. **Saved work** opens them again later. This does not create a Word or PDF file.

In **Saved work**, choose **Delete** beside a saved copy you no longer need and confirm. The open spreadsheet and document, templates, and exported files stay in place. If you delete the copy of work that is currently open, choose **Save work** to keep it again as a new saved copy. Deleted copies will not reopen automatically at startup.

**Save template** on the main screen creates a new template from the document in the right pane and its connected cell locations. Give it a unique name; a name already in use must be changed.

**Templates** opens your saved templates. Choose **Preview document** to use one with a new spreadsheet, or **Edit** to change its name, document, and connections. Editing has its own **Save changes** and **Cancel editing** buttons and keeps your previous work separate.

For another device or a backup copy, choose **Save file / Print**, then **Backup of my work** or **Template to share or reuse**. Saved work and templates kept only in the app are removed if the app's stored data is cleared.

Drag the middle divider to give either side more room. Double-click it to reset the sizing.

Choose **Expand workspace** beside the document row controls for larger spreadsheet and document views. It hides the top action buttons and three-step guidance while keeping the editing tools and row controls available. Choose **Restore layout**, or press **Escape**, to bring the top actions back for saving and exporting. If a dialog or page-setting menu is open, close that first.
