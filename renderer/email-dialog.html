PREPARE, REVIEW, THEN SEND

Email documents

Review each email and its document, then send from PaperLink using your company email server. You can also save drafts for your email app.

1. Set up the emails

Choose one email per row to send each person their own document.

Use an address your company allows this account to send from.

Email server settings

Ask IT for your outgoing SMTP server settings. Passwords are kept separately from saved work and templates.

The test message has no payroll data, attachments, or CC. Test connection checks the server and login without sending a message.

2. Attach the document

Each draft gets only its own document. All pages of that document are included. Matching file names get numbered automatically.

3. Review each email

Enter or edit To and CC directly in the email below. Each email keeps its own addresses. Separate several addresses with a semicolon.

Fill addresses from spreadsheet columns (optional)

Each row supplies its own addresses. Edits made directly in an email are kept until you choose Reset addresses for that email.

Accepted means the SMTP server accepted the email; it does not confirm inbox delivery. Sending stops on a failure or unconfirmed result. Previous acceptances are skipped unless you explicitly choose to resend.

        
Using company email or webmail?
Draft files (.eml) open in compatible email apps. Some apps open them as saved messages; choose Edit as new or an equivalent action. For webmail, copy the details above and attach the separate document. Saving the ZIP includes drafts, attachment copies, and email details. Opening a file does not put it in your account's Drafts folder automatically.
